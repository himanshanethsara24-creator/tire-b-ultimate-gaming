FREQUENTLY ASKED QUESTIONS

Does the setup require internet connection to install?

No! Both Setup.exe and TireB.exe are 100% self-contained. The installer includes all necessary runtime prerequisites so you can install and use it completely offline on any computer.

Not at all. Tire B uses native Windows EmptyWorkingSet memory flushing and software rasterization. When you minimize Tire B to game, its RAM drops to ~46 MB and idle CPU drops to 0.0%, leaving all hardware power free for your games.

Tire B connects to the decentralized Cloud Mesh. Retained status channels immediately push live statuses (🟢 Online Right Now with ping vs ⚪ Offline with exact last-seen timestamps) across all computers without waiting.
